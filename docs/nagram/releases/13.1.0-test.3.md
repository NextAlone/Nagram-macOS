# Nagram 13.1.0 (283359) 测试版 3

> [!WARNING]
> **这是 Nagram macOS 原生版的第三个测试版，不是最终交付版本。**
>
> - 功能还在移植中，可能存在若干尚未发现的问题，请不要用它替代你日常使用的客户端。
> - 遇到问题请在本仓库的 Issues 中反馈，附上系统版本和复现步骤。

这个版本从 Nagram Desktop 移植了 Instant View 翻译、DeepLX 翻译服务、多选复读和方角等功能，
应用改名为「Nagram」，并修正了正则过滤规则的输入。
功能列表见[测试版 1 的说明](13.1.0-test.1.md)，没有变化的部分不再重复。

## 本次更新

### 新功能

- Instant View 页面可以翻译：在 IV 窗口的「Aa」菜单里选「翻译」，再选一次切回原文。
  使用设置里选中的 Nagram 翻译服务，没有选择时使用 Telegram 自带的翻译。
  只有一种样式的段落会保留样式，混合样式的段落翻译后变成纯文本（其中的链接不能点击），含图片、公式或自定义表情的段落保持原文。
- 翻译服务新增 DeepLX 协议，默认地址 `http://127.0.0.1:1188/`，「模型」一栏填正式程度（formality）。
- 在多选的消息上右键，复读、复制复读和无引用转发会作用于全部选中的消息，菜单标题显示条数，发送后取消选择。
- 圆角设置可以选 0%，气泡、头像和搜索框都会变成方角；「跟随 Telegram」仍然是默认值。

### 修正

- 开启阅读间距或繁简转换时，选中文字引用回复会引用消息的原文，而不是显示出来的文字。
- 正则过滤规则的输入框可以正常编辑，长度限制和 Nagram Desktop 一致。
- 标签栏跟随主窗口的圆角裁切。

## 安装

1. 下载 `Nagram-13.1.0-283359-502f1350.dmg`，打开后把「Nagram」拖进「应用程序」。也可以下载 zip 解压。
2. 应用标识改了，所以它不会覆盖「Nagram Native」，账号和聊天数据会保留。确认新版本能登录后，
   可以删除旧的「Nagram Native.app」。macOS 会把它当成新应用，通知等系统权限需要重新授予，
   窗口大小之类只存在本机的界面偏好会恢复默认。
3. 这个测试版没有经过 Apple 公证，第一次打开会被 macOS 拦截。可以在「应用程序」里右键点它，选「打开」；
   或者在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/Nagram.app
   ```

下载后可以用 `SHA256SUMS` 核对文件：`shasum -a 256 -c SHA256SUMS`。

## 已知限制

和测试版 2 相同：

- 未经过公证，签名用的是开发证书，所以需要上面的手动放行步骤。
- 为了在没有描述文件的情况下运行，这个版本去掉了三项系统权限：从浏览器点击 t.me 链接直接跳转到应用、
  系统地图、共享钥匙串分组。相关功能在这个版本里不可用。
- 没有自动更新，新版本需要手动下载安装。
- 和 Nagram Desktop 同时安装时，`tg://` 链接由哪个应用打开取决于系统的默认设置。
- 还有一部分 Nagram Desktop 的功能没有移植，其中一些需要改动 Telegram 的核心库，会在后续版本中继续补齐。
