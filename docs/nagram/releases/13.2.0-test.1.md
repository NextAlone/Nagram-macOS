# Nagram 13.2.0 (283468) 测试版 1

> [!WARNING]
> **这是基于 Telegram for macOS 13.2 的第一个 Nagram 测试版，不是最终交付版本。**
>
> - 功能还在移植中，可能存在若干尚未发现的问题，请不要用它替代你日常使用的客户端。
> - 遇到问题请在本仓库的 Issues 中反馈，附上系统版本和复现步骤。

这个版本把上游同步到 Telegram for macOS 13.2，Nagram 自身的功能和 13.1.0 测试版 3 相同。
功能列表见 [13.1.0 测试版 1 的说明](13.1.0-test.1.md) 和 [测试版 3 的说明](13.1.0-test.3.md)，没有变化的部分不再重复。

## 本次更新

### 来自上游 13.2

- 右键菜单和表情回应选择器换成原生的玻璃效果。
- 修正内存泄漏：离开聊天后，打开过的聊天会被正确释放。
- 引用回复改为引用消息原文，而不是显示出来的文字。
- 富文本消息、Instant View 和文章编辑器的大量排版修正。
- 投票：可以在「收藏夹」中创建投票，投票后仍能添加选项，匿名投票的选项显示一致。
- 转发：分享窗口和「回复到其他聊天」会发到选中的话题，「隐藏发送者名称」不再沿用到下一次转发，
  从置顶列表转发到同一聊天不会丢失。
- 媒体查看器删除前会确认，新照片到达时停留在当前照片。
- 新增内置小组件引擎服务（`WidgetEngineService`），随应用一起安装。
- 其他界面、无障碍和稳定性修正。

### Nagram

- 小组件引擎服务使用 Nagram 的标识 `xyz.nextalone.nagram.WidgetEngine`。
- 标签栏的圆角裁切改用上游的实现，表现和之前相同。

## 安装

1. 下载 `Nagram-13.2.0-283468-cc7ea9ce.dmg`，打开后把「Nagram」拖进「应用程序」，覆盖旧版本。也可以下载 zip 解压。
2. 这个测试版没有经过 Apple 公证，第一次打开会被 macOS 拦截。可以在「应用程序」里右键点它，选「打开」；
   或者在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/Nagram.app
   ```

下载后可以用 `SHA256SUMS` 核对文件：`shasum -a 256 -c SHA256SUMS`。

## 已知限制

和 13.1.0 测试版 3 相同：

- 未经过公证，签名用的是开发证书，所以需要上面的手动放行步骤。
- 为了在没有描述文件的情况下运行，这个版本去掉了三项系统权限：从浏览器点击 t.me 链接直接跳转到应用、
  系统地图、共享钥匙串分组。相关功能在这个版本里不可用。
- 没有自动更新，新版本需要手动下载安装。
- 和 Nagram Desktop 同时安装时，`tg://` 链接由哪个应用打开取决于系统的默认设置。
- 还有一部分 Nagram Desktop 的功能没有移植，其中一些需要改动 Telegram 的核心库，会在后续版本中继续补齐。
