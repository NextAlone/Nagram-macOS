# Nagram Native 13.1.0 (283357) 测试版 1

> [!WARNING]
> **这是 Nagram macOS 原生版的第一个测试版，不是最终交付版本。**
>
> - 功能还在移植中，可能存在若干尚未发现的问题，请不要用它替代你日常使用的客户端。
> - 「Nagram Native」是临时名称，正式发布前可能会修改。
> - 遇到问题请在本仓库的 Issues 中反馈，附上系统版本和复现步骤。

Nagram Native 是基于 [Telegram for macOS](https://github.com/TelegramMessenger/telegram-macos) 原生客户端的 Nagram，
把 Nagram Desktop（Qt 版）的增强功能移植到了 macOS 原生界面上。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 13.1.0 (283357)，测试版 1 |
| 上游基线 | Telegram for macOS `master`（2026-10-29，`de608bb0`） |
| 系统要求 | macOS 12 及以上 |
| 架构 | 通用二进制（Apple Silicon 和 Intel） |
| 应用标识 | `xyz.nextalone.nagram.macos` |

## 安装

1. 下载 `Nagram-Native-13.1.0-283357-6b7eeb82.dmg`，打开后把「Nagram Native」拖进「应用程序」。也可以下载 zip 解压。
2. 这个测试版没有经过 Apple 公证，第一次打开会被 macOS 拦截。可以在「应用程序」里右键点它，选「打开」；
   或者在终端执行：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Nagram Native.app"
   ```

3. 第一次打开需要登录。它的数据和 Nagram Desktop（Qt 版）、Telegram 官方客户端互相独立，可以同时安装。

下载后可以用 `SHA256SUMS` 核对文件：`shasum -a 256 -c SHA256SUMS`。

## 已知限制

- 未经过公证，签名用的是开发证书，所以需要上面的手动放行步骤。
- 为了在没有描述文件的情况下运行，这个版本去掉了三项系统权限：从浏览器点击 t.me 链接直接跳转到应用、
  系统地图、共享钥匙串分组。相关功能在这个版本里不可用。
- 没有自动更新，新版本需要手动下载安装。
- 和 Nagram Desktop 同时安装时，`tg://` 链接由哪个应用打开取决于系统的默认设置。
- 还有一部分 Nagram Desktop 的功能没有移植，其中一些需要改动 Telegram 的核心库，会在后续版本中继续补齐。

## 功能列表

下面是这个版本已经可以在「设置 → Nagram」中使用的功能。设置项的含义和 Nagram Desktop 一致，
配置文件和收藏夹备份可以在两者之间通用。

### 界面

- 消息气泡圆角、头像圆角（可用于论坛和频道私信）、搜索框圆角
- 文字消息宽度，加宽频道文字消息
- 隐藏气泡尾巴，回复和引用使用主题颜色，隐藏回复缩略图
- 忽略对话的自定义主题和壁纸（可分别对私聊、频道设置）
- 隐藏应用图标角标
- 通知延迟，免打扰时段

### 会话列表

- 消息预览行数，隐藏收藏夹和归档的消息预览，列表时间显示秒
- 隐藏动态，隐藏赞助消息和搜索广告，隐藏代理赞助频道，隐藏 Premium 推广提示，隐藏生日提示
- 启动时打开的文件夹，隐藏「全部会话」文件夹，隐藏文件夹未读数
- 在文件夹中显示归档入口
- 在文件夹列表中显示收藏夹和归档（侧栏和顶部标签都支持，归档显示未读数）
- 不在全局搜索中搜索公开聊天
- 在联系人列表中标记双向联系人

### 消息

- 时间显示秒，服务消息显示时间，转发消息显示原始发送时间
- 显示消息 ID
- 显示精确的浏览数和回复数，隐藏浏览数，在浏览数旁显示转发数
- 隐藏频道消息签名
- 隐藏「已编辑」标记、自定义标记文字或改用图标
- 隐藏消息反应（可分别对私聊、群组、频道设置），隐藏右键菜单和多选时的反应面板
- 关闭 Premium 贴纸特效、表情互动特效、消息特效
- 直接显示剧透内容，隐藏快速转发按钮
- 隐藏推荐频道，加入频道后折叠相似频道
- 隐藏会员标识和表情状态，隐藏收藏夹标签栏，隐藏私聊中对方的输入状态
- 阅读时在中西文之间加空格，阅读时简繁转换
- 简化回复和引用样式，不播放动态头像
- 把已读和表情列表移到消息菜单顶部

### 输入与发送

- 隐藏输入框按钮：附件、表情、录音、命令、机器人菜单、自动删除、礼物、AI、「发送身份」、频道底部静音
- 鼠标悬停时不弹出表情面板，点击机器人命令时先填入输入框
- 输入框提示文字，快捷回复（输入框右键插入）
- 关闭自动 Markdown，默认不显示链接预览，默认代码语言
- 发送或编辑时在中西文之间加空格，发送时简繁转换
- 发送贴纸、GIF 前确认，私聊通话前确认
- 先发送转发内容再发送附言
- 频道底部按钮改为进入讨论组
- 加高提及、话题标签和命令的候选列表

### 消息菜单

- 复读、无引用复读、无引用转发（可设置复读前确认、频道中不提供复读、复读后滚动到最新消息）
- 选择此人的消息、此用户的其他消息、选择区间内的消息、选择已加载的全部消息
- 媒体信息、消息详情、删除已下载的文件
- 快捷评价（填入回复草稿，不自动发送）
- 在本地隐藏此消息、隐藏此人的消息
- 保存到收藏夹、复制为 Markdown
- 总结（需要配置总结服务）
- 自定义每个菜单项的显示或隐藏

### 媒体与贴纸

- 贴纸大小、贴纸面板尺寸、隐藏贴纸时间、最近使用贴纸数量
- 隐藏群组贴纸、推荐贴纸、推荐表情、GIF 推荐分类、新私聊的问候贴纸
- 关闭聊天中的视频自动播放，缩小 GIF 显示尺寸
- 不自动下载可执行文件和压缩包
- 导出、导入已安装贴纸包列表（格式与 Nagram Desktop 相同）

### 隐私与资料

- 遮盖我的手机号，演示模式
- 隐藏已读时间提示、分享手机号提示
- 在资料页显示 ID 和数据中心，隐藏资料页礼物，隐藏「创建待办清单」入口
- 姓名顺序，给对话设置本地备注名
- 允许复制和保存受保护的内容，忽略内容限制，自动显示敏感媒体
- 不发送我的输入和上传状态

### 翻译与总结

- 用自己配置的服务翻译消息：OpenAI 兼容接口、Anthropic、DeepL、Google、Microsoft、Yandex
- 服务实例管理：预设、密钥保存在系统钥匙串、连接测试
- 消息总结

### 规则

- 本地消息过滤：按正则隐藏、遮盖或替换文字，可过滤自己发出的消息、移除过多的组合附加符号、按发送者隐藏
- 关键词提醒
- 打开 Telegram 官方网页时不自动登录，跳过打开链接确认
- 点击话题标签时的搜索范围
- 网页应用窗口宽度和高度

### 配置管理

- 查看已修改的设置，导出和导入设置（文件格式与 Nagram Desktop 相同）
- 收藏夹云端备份：备份、恢复、立即同步、删除云端备份、设置变更后自动备份，与 Nagram Desktop 共用同一份备份
- 复制诊断信息，调试日志，在文件夹中显示日志文件
- `tg://nasettings/…` 链接直接打开对应的设置项
