> **这是 Nagram macOS 原生版的第二个测试版，不是最终交付版本。**
>
> - 功能还在移植中，可能存在若干尚未发现的问题，请不要用它替代你日常使用的客户端。

功能列表见[测试版 1 的说明](13.1.0-test.1.md)，没有变化的部分不再重复。

## 本次更新

### Nagram

- 导入设置时在可滚动的窗口里预览改动，并列出这个客户端还没有对应功能的选项。
- 导入的选项需要重启才生效时会提示重启。
- 导入时按 Nagram Desktop 的规则校验取值，导入的行内机器人规则默认关闭。

### 来自上游

- 界面：资料页头像铺满顶部，从设置返回时恢复原来的侧栏，热门联系人、最近聊天和搜索结果的右键菜单更完整，
  搜索结果菜单可标记已读或未读，搜索历史中的聊天可在新窗口打开，弹出窗口跟随主题。
- 消息与输入：开启实时翻译时发出的消息也会翻译，复制的代码和引用保留格式，发送贴纸或 GIF 后保留已输入的文字，
  文章草稿在重启后保留，AI 编辑器保留草稿格式，修正预览发送和文章编辑器里的输入法问题。
- 表情：可以从「最近使用」里移除单个表情，修正重复的表情和肤色，表情包预览可直接设为状态。
- 群组与频道：在最近操作里可以限制或封禁成员并显示剧透媒体，一键取消话题静音，
  文件夹里重新排序后保持置顶顺序，可从链接加入论坛群组的视频聊天。
- 媒体：修正没有 Telegram 元数据的 AV1 视频的播放和拖动，图库里的视频响应系统的播放/暂停键。
- 隐私与安全：不导出开启了「限制保存内容」的聊天，受保护的消息不能从翻译窗口复制，
  钱包确认前明确校验生物识别，「活跃设备」信息更详细。
- 其他：启动时不再等待 `system_profiler`，右键菜单不会超出屏幕下沿，快速切换可以输入数字。

## 安装

1. 下载 `Nagram-Native-13.1.0-283358-7b61e7e6.dmg`，打开后把「Nagram Native」拖进「应用程序」，覆盖测试版 1。
   也可以下载 zip 解压。账号和设置会保留。
2. 这个测试版没有经过 Apple 公证，第一次打开会被 macOS 拦截。可以在「应用程序」里右键点它，选「打开」；
   或者在终端执行：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Nagram Native.app"
   ```

下载后可以用 `SHA256SUMS` 核对文件：`shasum -a 256 -c SHA256SUMS`。

## 已知限制

和测试版 1 相同：

- 未经过公证，签名用的是开发证书，所以需要上面的手动放行步骤。
- 为了在没有描述文件的情况下运行，这个版本去掉了三项系统权限：从浏览器点击 t.me 链接直接跳转到应用、
  系统地图、共享钥匙串分组。相关功能在这个版本里不可用。
- 没有自动更新，新版本需要手动下载安装。
- 和 Nagram Desktop 同时安装时，`tg://` 链接由哪个应用打开取决于系统的默认设置。
- 还有一部分 Nagram Desktop 的功能没有移植，其中一些需要改动 Telegram 的核心库，会在后续版本中继续补齐。
